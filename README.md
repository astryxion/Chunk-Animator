# Chunk Animator

Animate chunks as they load! Instead of appearing instantly, chunks rise from below, drop from above, or slide in from the side. Unlike the original 1.20.1 version, this build is compatible with modern rendering mods such as Embeddium, Xenon, and Rubidium.
